# Instruções de utilização

## Estratégia de Organização de Codificação 

Nesse primeiro eixo do curso, para simplificar o entendimento dos demais integrantes da equipe de desenvolvimento, houveram dias onde cada um realizou a edição do código e realizou o envio para o GitHub. Decidimos realizar desta forma devido os demais desenvolvedores não terem entendimento para trabalhar cordenadamente, então decidimos que, a cada dia um ficaria responsável em editar uma parte do projeto e subir para o Github.
